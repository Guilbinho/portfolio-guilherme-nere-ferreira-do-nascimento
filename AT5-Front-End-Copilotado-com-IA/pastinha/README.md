# 🎭 Teatro de Produtividade

## 📝 Descrição do Projeto
Este projeto consiste em um site informativo sobre o **"teatro de produtividade"**: a prática de parecer produtivo em vez de realmente produzir, como manter o status "online" o dia todo, responder mensagens na hora para mostrar presença e lotar a agenda de reuniões.

Desenvolvido como parte da disciplina de **Desenvolvimento Front-End Para Web (2026.2)**, na Atividade Prática Avaliativa *Front-end & Copilotagem com IA — O Futuro do Trabalho e as Características Socioemocionais da Geração Atual* (UNICID, Prof. Diego Marques de Carvalho), o site explica o conceito e seus efeitos, e traz uma proposta de reflexão: medir esforço não é o mesmo que medir resultado.
