# 🌐 Site Básico em HTML5 — Jarb Streetwear

## 📝 Descrição do Projeto
Este projeto consiste em um site institucional de 5 páginas para a **Jarb**, uma marca fictícia de streetwear autoral. O objetivo da atividade era construir uma estrutura multipágina usando HTML5 semântico, com navegação entre as páginas e identidade visual consistente em todo o site.

Desenvolvido como parte da disciplina de **Desenvolvimento Front-End Para Web (2026.2)**, o site apresenta a marca, o catálogo de produtos, o lookbook da coleção "Lua Roxa", a história da Jarb e uma página de contato com formulário.

### 📄 Páginas do site
| Arquivo | Conteúdo |
| :--- | :--- |
| `index.html` | Página inicial com apresentação da marca e destaque da coleção atual |
| `produtos.html` | Catálogo com 6 produtos em cards (camiseta, moletom, calça, boné e acessórios) |
| `lookbook.html` | Editorial da coleção e sugestões de combinações de looks |
| `sobre.html` | História da marca e etapas do processo de produção |
| `contato.html` | Dados de contato e formulário de mensagem |

## 📊 Resultados e Aprendizados
* **Estrutura multipágina:** montei um site com 5 páginas ligadas por um menu de navegação, com indicação da página atual (`aria-current`).
* **HTML semântico:** usei as tags corretas para cada parte do conteúdo, o que melhora a organização do código e a acessibilidade.
* **Acessibilidade básica:** incluí texto alternativo nas imagens, `label` associada a cada campo do formulário e ícones decorativos marcados com `aria-hidden`.
* **CSS reutilizável:** um único arquivo de estilos (`css/style.css`) controla a identidade visual de todas as páginas, com paleta de cores definida por variáveis.
* **Organização de arquivos:** separei estilos (`css/`) e imagens (`images/`) em pastas próprias.
